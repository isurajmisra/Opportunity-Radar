# Sources

Use stable IDs such as S001. Inline citations in report files should link to these source URLs.

| Source ID | Provider / retrieval method | Title | Publisher | URL | Publish/update date | Event/observation date | Access date | Geography/population | Industry/category | Source tier/type | Primary/secondary | Fetched (full page / snippet only / blocked) | Claims supported | Independence cluster | Corroborates / contradicts | Limitations |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|

Blocked or inaccessible sources stay listed with "blocked" and the alternatives tried. They are coverage limitations, never evidence of absence.
